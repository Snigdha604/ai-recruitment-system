# 🤖 AI Recruitment System

## 📌 Overview
The AI Recruitment System is designed to automate the hiring process by analyzing resumes and matching candidates with job requirements using Machine Learning and Natural Language Processing (NLP). It helps reduce manual effort and improves hiring efficiency.

## 🚀 Features
- 📄 Automated resume screening  
- 🧠 AI-based candidate ranking  
- 🎯 Job-role matching  
- ⚡ Faster and more efficient hiring process  

## 🛠️ Tech Stack
- Python  
- Machine Learning / NLP  
- Libraries: Pandas, NumPy, Scikit-learn

## ⚙️ Installation
git clone https://github.com/your-username/ai-recruitment-system.git  
cd ai-recruitment-system  
pip install -r requirements.txt  

## ▶️ Usage
python main.py  

## 📊 How It Works
1. Upload candidate resumes  
2. System processes text using NLP  
3. Extracts key skills and experience  
4. Matches candidates with job roles  
5. Ranks candidates based on relevance
